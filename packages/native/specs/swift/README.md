# Swift specs

Rules shared by every Astryx component written in Swift, for iOS and macOS.

A single component's spec lives beside the core component's spec:
`docs/specs/components/<ComponentRoot>/<Name>.swift.spec.md`, named as the core
component (`Button.swift.spec.md`, `TextInput.swift.spec.md`) and copied from
[`../TEMPLATE.md`](../TEMPLATE.md).

Start with a component that already has a generated contract in
`packages/native/src/components/`.
