# Swift specs

Rules shared by every Astryx component written in Swift, for iOS and macOS.

A single component's spec lives in that component's own folder, beside its
views: `packages/native/apple/Sources/Astryx/<Name>/<Name>.spec.md`, named as the
core component (`Button.spec.md`, `TextInput.spec.md`) and copied from
[`../TEMPLATE.md`](../TEMPLATE.md).

Start with a component that already has a generated contract in
`packages/native/src/components/`.
