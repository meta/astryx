# Charts planning and verification

These package-local records track the canary-only Charts package while its API,
visuals, and verification mature:

- [`CHARTV2_PHASE1_PLAN.md`](./CHARTV2_PHASE1_PLAN.md): implementation sequence and evidence.
- [`CHARTV2_STAGE1_DESIGN.md`](./CHARTV2_STAGE1_DESIGN.md): API and correctness research.
- [`CHARTV2_READINESS.md`](./CHARTV2_READINESS.md): launch-readiness snapshot.
- [`CHARTV2_VERIFICATION_CHECKLIST.md`](./CHARTV2_VERIFICATION_CHECKLIST.md): verification matrix.

The historical `ChartV2` name remains in these filenames because the records
predate extraction into `@astryxdesign/charts`. Current consumer guidance lives
in the package [`README`](../README.md) and `.doc.mjs` files.
