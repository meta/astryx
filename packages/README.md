# /packages

Published npm packages for the Astryx design system.

<!-- SYNC: When files in this directory change, update this document. -->

| Directory | Package                 | Purpose                                                                |
| --------- | ----------------------- | ---------------------------------------------------------------------- |
| `core/`   | `@astryxdesign/core`    | Core UI components, theme system, and utilities                        |
| `cli/`    | `@astryxdesign/cli`     | CLI tooling: component docs, templates, scaffolding, codemods          |
| `build/`  | `@astryxdesign/build`   | Build plugins for StyleX source builds (Babel, PostCSS, Vite)          |
| `themes/` | `@astryxdesign/theme-*` | Visual themes (neutral, butter, chocolate, matcha, stone, gothic, y2k) |
| `vega/`   | `@astryxdesign/vega`    | Vega/Vega-Lite chart wrapper (canary only)                             |
| `charts/` | `@astryxdesign/charts`  | Chart components — themeable wrappers over a peer engine (canary only) |
| `lab/`    | —                       | Experimental components (not published)                                |
