Install in your app (paths are relative to a file in src/; adjust if yours lives elsewhere):

  import { Theme } from '@astryxdesign/core/theme';
  import { amberTheme } from './themes/amber';
  import './themes/amber.css';

  <Theme theme={amberTheme}>
    <App />
  </Theme>

Or with a <link> tag:

  import { Theme } from '@astryxdesign/core/theme';
  import { amberTheme } from './themes/amber';

  <link rel="stylesheet" href="./themes/amber.css" />
  <Theme theme={amberTheme}>
    <App />
  </Theme>

[note] The built themes name fonts they do not load:
  "Space Grotesk" (amber, basil, fjord, grove, kelp, lagoon)
  "JetBrains Mono" (amber, dune, grove, iris, juniper, meadow, nimbus)
  "Figtree" (cedar, harbor, meadow)
  The built CSS only sets font-family; load these in your app, or every
  browser quietly falls back.

  Google Fonts (add :wght@... axes as your theme's weights require):

    <link rel="preconnect" href="https://fonts.googleapis.com" />
    <link rel="preconnect" href="https://fonts.gstatic.com" crossorigin />
    <link rel="stylesheet" href="https://fonts.googleapis.com/css2?family=Space+Grotesk&family=JetBrains+Mono&family=Figtree&display=swap" />

  Self-hosted (repeat per family and weight):

    @font-face {
      font-family: "Space Grotesk";
      src: url('/fonts/space-grotesk.woff2') format('woff2');
      font-display: swap;
    }
