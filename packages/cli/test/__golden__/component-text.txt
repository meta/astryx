# AcmeCard

A zorblax card that groups one topic.

**Import:** `import { AcmeCard } from '@acme/kit';`

## Usage

```tsx
<AcmeCard title="..." />
```

## Props

- `title`: `string` **(required)** - Heading text.
- `tone`: `'calm' | 'loud'` = `'calm'` - Visual weight.

Full output, with anatomy, best practices, examples and theming (classes, data attributes, CSS variables): `pnpm exec astryx component AcmeCard --detail full`
