[experimental] `astryx experimental theme`: a refused `preview app --theme` or `preview add` writes nothing: a stale theme it builds first is put back when the build fails (a theme source that does not load), so the same command is refused again rather than copying an old build. `preview app --theme` refuses a theme stylesheet url that leads out of the theme folder (the new app would not build), a theme file too large for one read, and one that cannot be read, each by name (a read, never called a write). A named pipe or a device at a file the editor reads (the preview record, a page, a picture, the pictures record) is never opened, so no command hangs on one. Theme image names are URL text (`a%20b.png` is "a b.png"), and a quoted url may hold parentheses; an image that cannot be read is left out of the previews with a note. A section sheet's pictures go with the others when the look changes, and the command that takes them again is named. A starter app names the weights of a font it adds that it does not load. `preview add` reads a typed dash form of its options, and beside a description offers only a `--template` page this app can add; `--top` beside a default page, or alone, offers the command without it; an empty `--theme` offers the preview command with each theme.
