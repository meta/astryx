[experimental] A gradient the theme editor writes for a variant, a state or a mode is built as the background longhands its value gives (`background-image`, and a layer's own position, size and repeat), in any word order, for a prefixed gradient, a `url()` or an `image-set()` too. A layer with a word those longhands do not take, such as an attachment (`fixed`) or a box, keeps the `background` shorthand as typed. A background longhand set on the whole part, such as `background-repeat no-repeat` on a button, now still applies in every variant and state, so a hover gradient no longer tiles. When the build still writes a shorthand there (a plain `background` color for one variant) and it resets such a longhand, the result says which.
