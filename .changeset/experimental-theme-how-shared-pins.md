[experimental] `astryx experimental theme editor how` reads each ask through one shared reader and holds every answer to what the theme shows. A kept variant or state is pinned from the base theme's own rule (a kept hover keeps Core's tint, as a variant's fill is its background color). A color word before a part names that variant ("make blue cards rounder") or is refused when the part has none ("red buttons"). One removal-list reader takes "take away the card's border and shadow", "remove the card border, shadow and background" and "remove the dialog's shadow and the card border". "dark-mode" is "dark mode". "at most", "no more than" and "a maximum of" are limits, and a limit already met changes nothing. A button's radius is written as its corner token, so button groups keep their square joins. A one-mode shadow on a part that draws a shadow in the other mode (a card's selection ring) is refused. A part given a role color keeps a readable label in every variant. Vibrancy is measured on the accent colors the theme shows. State excepts ("except disabled", "keep disabled ones as they are") go through one state reader; an except set cannot keep, or a text size that differs by screen, is said, and the plain answer is not offered. A step aimed only at an excepted variant is left out. "Darker than the page" steps past the page in each mode; a page reference is never written. A link that reads a shared text color keeps it. "letter-spaced" is letter spacing, and "side nav section headings" is the side nav heading. A refusal's own command is offered when it does what was asked, and `--at` without a picture names a command that runs.
