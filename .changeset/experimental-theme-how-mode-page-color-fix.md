[experimental] `astryx experimental theme editor how`: a color said for one mode's page keeps the mode on what follows it. "dark mode is plum, gold buttons" writes the gold buttons for dark mode only, as before the page reading. A color with a word the page reader does not read beside its hue ("dark mode is cool navy", "midnight navy", "bright red", "a dusty plum") is read as before instead of being refused.
