[experimental] `astryx experimental theme editor how`: a color said for one mode's page keeps the mode on what follows it. "dark mode is plum, gold buttons" (or ". gold buttons", "; gold buttons") writes the gold buttons for dark mode only, as before the page reading, and after a second mode's page ("light mode is pale blush, dark mode is plum, gold buttons") they take that nearer mode. A color with a word the page reader does not read beside its hue is no longer made a page, so it answers as before the page reading: "dark mode is cool navy" writes the dark neutral, and "midnight navy", "bright red" or "a dusty plum" match nothing, instead of answering that no part is called "page cool".
