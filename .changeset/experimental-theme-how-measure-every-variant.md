It also answers: headings smaller (each level's own size when the type dial would change weights), "the text 2px bigger", "the card border 1px thicker", sizes written "48px by 48px", heading ranges for any property ("headings 1 through 3 bolder") and an excepted level ("all headings red except h1", which keeps h1 as it is), a heading level past 6 (said), "the dialog the same color as the page" (the page's own color; the page is not changed), "no shadow and no border on dialogs" (both on that part), "0 steps more" (nothing), "everywhere except", a backdrop more see-through (a lower alpha), a dialog shadow darker, lighter or with no blur from the shadow it has, "remove the card background" (transparent), "thicker borders" from the width there now, a token pointing at another token, a dark-only theme's accent from its dark value, "rounder cards without shadows", "slightly lighter than black", and value questions about a part's font, shadow, opacity and fill, in the variant and mode they name.
