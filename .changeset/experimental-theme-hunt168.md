[experimental] `astryx experimental theme editor`: a problem a change makes leads its result. The status line counts the new problems, and each follows under it with the command that fixes it: the text token set where the text sits, or the border color, for the mode, to the black or white that reads there. A color that fails its contrast check is a new problem too. `show` ends with `openProblems`, every contrast problem the theme has now with its fix, in text and JSON. A text token set on the part the text sits on (card text on the card) now counts for the text inside it, so following that fix clears the problem, and a border set again for one mode is measured as set.
