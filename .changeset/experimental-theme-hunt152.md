[experimental] `astryx experimental theme editor`: every dash form of an option (a hyphen before a dash, minus signs) is read as the option, never glued into a value. A dial name with a space for its dash (`"text size"`) is the dial. A set with no thing points to the settings it takes. A typo as near two values offers each (`tightr`: tight and tighter). A typo of a system font the build knows (`arail`, `Menol`) is refused with that family. `undo t headings wdie` removes the half its reading names. show, and undo with no history, on a damaged saved value offer its undo and set's repair beside it; a saved base in other letters or with a typo of a base that is not installed reads as that base, with its install first, in show as in a change. An entry saved in a form set reads when typed (`{"corners": "pill"}`, `"corners pill"`) is read as that setting. An undo names the change now on top, which the next undo takes back.
