[experimental] In `astryx experimental theme editor how`, a status's text at a typed size ("warning text 10px") offers that size on each part that shows it, never a step bigger; a size and a weight said together ("warning text 10px bold") are both written, and the answer names only the parts it writes a line for. A status's text size or weight on a banner goes only into tokens its title or description read and its buttons and icon do not; a token its buttons read too (the title's label size) is left as it is, and the answer says so.
