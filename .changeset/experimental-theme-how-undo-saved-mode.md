[experimental] `astryx experimental theme editor how`: an undo that says a mode ("undo the light mode accent change", "in dark mode, reset the card background") takes back the setting the theme saves for that mode only, instead of both. A setting saved the same for both modes is named, with how to take it back in both; when the theme saves nothing for that mode, the answer says so. A change said earlier in the same ask is what the undo takes back, before any saved setting.
