[experimental] `astryx experimental theme editor how`: "a font like Tiempos" (or "a typeface like …") is read as that family, as "Tiempos-like" already is, with the same exceptions: a shipped font the name begins wins, and a kind the clause names that the family's own name does not say is written instead ("a font like Tiempos for code" writes the monospace font on code).
