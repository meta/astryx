[experimental] `astryx experimental theme editor`: `--state disabled` reaches the control inside only on a part that holds one control (a typeahead), never a radio list, input group or field. `corners none`, `sharp`, `zero` and `0%` are square; `spacing none` names the tightest rung. Undoing a part's state setting names the group's setting for the same state. `focus-within` is taken on a part that holds content in a prop (a chat composer's input) or children (a popover).

A token in your own theme source that is not text, alone or in a pair, is refused before anything is written, with an example of the token's own type. A helper imported as `./x.js` counts when only `x.ts` exists. A `set` refused for your own file suggests reading it. The compile help lists the editor-theme refusals.
