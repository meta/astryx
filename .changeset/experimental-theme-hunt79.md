[experimental] `astryx experimental theme editor how`: amounts read the way they are said. Zero, none and no set that property to 0 or none in any position ("card corners zero", "zero border", "opacity zero", "no letter spacing", "remove the top padding"), and a padding side reads its own value now. One amount reader takes "up 20%", "increase by 50%", "2/3", "two thirds", "three quarters", "twice as small", "a third again" and a lone "½" as a share of now; a bare percent radius is refused with the command that scales the radius instead. "Two steps bigger" gives two dial steps, "2 spacing units" is twice the spacing unit token, a size such as "24x16px" on padding is that exact padding, and "+4px", "-2px" or "4px more" on padding, gap, radius or text size is the value now plus or minus that length. See-through amounts set opacity ("half transparent", "10% transparent", "50% opacity"), "more opaque" raises it, and "5% gray" is gray at 5% alpha. Color amounts apply to text and hover colors; warmer and cooler move the hue, not the lightness; lighter and darker change the color of borders, dividers and links, and keep the alpha of rgb(), hsl() and oklch() colors. Small, secondary and supporting text and fine print change the supporting text size; "h1 800" is a weight; "h2 through h4" changes each level; "h1 800 and the other headings 600" sets every other level; "h1 twice as big as body text" and "h3 the same size as h2" take the other size times the amount; "and the active one blue" keeps that state. Thinner text is a lighter weight, a sharper shadow halves the blur of the part's shadow and a softer one doubles it, a thinner scrollbar says there is no scrollbar part, the overlay's lighter or darker changes only its alpha, and wider no longer sets a made-up 720px width. `how paddingLeft`, `how borderRadius` and other camelCase names look up that property.
