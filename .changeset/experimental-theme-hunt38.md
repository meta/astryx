[experimental] `astryx experimental theme editor`: a theme's own `<theme>.theme.ts` deleted by hand is written again by `show` or the next `set`, which say so, and `compile` of it suggests `editor show`. `text-size` and `type` name an exact role size they keep (`--text-body-size`, heading sizes), and a role or whole-theme font names an exact `--font-family-<role>` it keeps, with the undo that frees it; undoing a role font names that token as what applies. A value pasted with `!important` says it is not used and suggests the value without it, and the font dial reads a pasted `Georgia, serif;` or a comment as the font meant.
