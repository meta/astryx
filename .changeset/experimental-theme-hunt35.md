[experimental] `astryx experimental theme editor`: a word that names a JavaScript object built-in (`constructor`, `__proto__`, `toString` and the like), given as a value, a scope, a state, a flag or a `how` question, gets the same refusal as any other unknown word instead of an `ERR_UNKNOWN` crash. Every word table the editor reads with typed text now answers only for its own entries.
