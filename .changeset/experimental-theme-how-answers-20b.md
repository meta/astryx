[experimental] `astryx experimental theme editor how`: "bolder" or "a bit lighter" headings move one rung from the headings rung the theme sets (and say so when there is no rung further), and "a bit bigger" text moves a numeric text size by the dial's own step. `how <theme> <question>` takes a first word that names an existing theme as the theme, as `set`, `show` and `undo` do.
