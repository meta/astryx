[experimental] `astryx experimental theme editor how`: a color said for one mode's page keeps that reading when a "with", "and" or "but" says more after it. "light mode should be cream with blue buttons" is the light page plus blue buttons, and "dark mode is navy and light mode is cream" gives each mode its page. A clause after a comma and an "and" ("make the buttons rounder, and dark mode should be a deep dark plum") is read the same way. One that only adds a color ("dark mode should be navy and white") is left as said.
