[experimental] `astryx experimental theme editor set` says where a page color shows in more cases: making a theme one-mode (`mode dark-only` or `light-only`) gives the page note once, a fill on the main panel (`--on layout-content`) says it covers that panel, not the page, and names the page color line, and a fill on the shell frame (`--on layout`) is refused with the page color line first. An app embedded in a page it does not own gets no page note.
