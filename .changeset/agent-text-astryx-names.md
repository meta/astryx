[docs] The agent docs `astryx init` writes, and the computer-level skill, name the Astryx prop names that differ from other libraries in the workflow's third step: buttons, badges, tokens and tabs take their text in `label` (Text, Heading and Link take children), booleans start with `is` or `has`, and every input takes `value` and `onChange`. An agent that writes props before it reads a component now writes these right far more often. Run `astryx upgrade` or `astryx init` to refresh a project's agent docs.
