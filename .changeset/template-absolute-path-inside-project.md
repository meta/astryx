[fix] `astryx template <name> <path>` and `astryx template --cdn <path>` accept an absolute path inside the project root, also through a symlinked project folder. It is written exactly as its relative path. An absolute path outside the project is still refused with `ERR_PATH_TRAVERSAL`. For `astryx template <name> <path>`, the receipt says the path was written as its relative path (`data.givenPath` in `--json`), and the refusal names a command that writes inside the project and the command that prints the source without writing anything. The named path is one the project builds and serves: in a Next app, a page goes to the App Router folder (`app/<name>`, or `src/app/<name>`, inside the route group with the root layout when that folder has none of its own), or, with only the Pages Router, to the page file `pages/<name>.tsx`; a block goes to `app/components/<name>` with a root `app/` folder, `components/<name>` with only a root `pages/` folder, else `src/components/<name>`; every other project gets `src/pages/<name>` and `src/components/<name>`. When that path exists or another page already serves its URL, the name becomes `<name>-2`, `<name>-3` and so on. Next refuses to build a `src/pages/` folder beside a root `app/` folder, and two pages at one URL. For `--cdn`, the receipt is unchanged, and the refusal names `astryx template --cdn cdn.template.html`.
