[experimental] `astryx experimental theme editor set … --on <part>`: a CSS property set on a part names every part drawn as that part inside other components (a calendar's nav arrow, a code block's copy button and an input's clear button are buttons too), with the one line that keeps each as Core draws it (`embedded`), so a button look can stop there when wanted. A part that has its own setting of the same thing is not named.
