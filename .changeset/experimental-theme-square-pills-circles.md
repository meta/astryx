[experimental] `astryx experimental theme editor set … corners square`: square corners square every pill that is a styling choice (badges, progress tracks, a switch's track) and keep the parts drawn as circles round (avatars, a switch's or slider's thumb, step dots), told apart by each part's own box; the result names the circles kept, with the line that squares one, instead of a line that squares every circle too.
