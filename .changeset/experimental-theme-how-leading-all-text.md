[experimental] `astryx experimental theme editor how` says, for a line height asked with no part ("1.5 line height"), that the supporting and large text, the headings, the labels and code keep their own leading, and gives the lines that change them. "All text", "every text" or "everything" with a line height now sets the large text, heading and code leadings too, by the same change; the label and supporting leadings keep their own, as they set control and row heights. On a base whose touch phone rule sets its own type scale, a body line height answer says that scale sets the line heights on touch phones. An ask that keeps some text out ("everything except headings") sets the body leading only, as before.
