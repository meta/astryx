[experimental] `astryx experimental theme editor how`:

- A one-line look written as a list ("clean and trustworthy like a bank: blue and gray, lots of data on screen") takes each piece a setting reads and names the words none reads. "lots of data on screen" means compact spacing. "dark purple theme" sets dark mode and a purple accent. "at night" means dark by default, and "easy to read" means larger text. "pastel pink" is a light pink, "deeper blue" is a dark blue, and "red only for alerts" sets the danger color. "dark mode first" works like "dark by default".
- "make the blue a bit darker" changes the theme color with that hue.
- "buttons medium weight" sets a weight, not the medium size. "headings semibold, not bold" is one ask. "large bold headings" and "bigger, bolder headings" also make headings bigger. "table headers uppercase 11px" keeps the 11px. "use the system font" sets the font.
- A border asked for one mode on a part that draws its own shadow becomes a border whose color is transparent in the other mode.

`astryx experimental theme editor set`: a page background on the app shell keeps a background a setting gives the main content area, whichever was set first.
