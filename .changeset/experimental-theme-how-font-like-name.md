[experimental] `astryx experimental theme editor how`: a family a font is said to be like ("MS Sans Serif-like pixel sans") sets that family as typed, unless the clause names, as a whole word, a kind (serif, monospace) that the family's own name does not say or the name begins a shipped font's family; before, the system stack was written and the family was lost. `astryx experimental theme editor set font`: an older name of a system family ("MS Sans Serif") is followed by the family that replaced it ("Microsoft Sans Serif"), then the system fallbacks.
