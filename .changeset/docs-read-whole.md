[docs] `astryx docs <topic>` prints the topic whole, as `--json` already did, so a guide's first read carries its rules and examples. A topic whose whole doc is over the most one docs read may return still lists its sections. `--index` lists the sections of any topic, and `--full` prints any topic whole.
