[experimental] `astryx experimental theme editor`: a typo of a font preset reads as that preset when the preset and the system family it names both match (`Verdena`, `Segoe IU`); a family near a system font only (`Times New Romna`, `Arail` in a list) is kept as typed, with a note whose line sets that font. `show` and `compile` give set's repair for a damaged saved value beside its undo, as every change does, and an entry saved in a typed form (`corners: pill`, `red --on card`) gets the reading set gives it. The editor's own printed setting line pasted back (`corners = pill (whole theme)`, `opacity = 0.5 on card`) carries its scope. A dial saved for one mode is refused as `set` refuses `--mode` on it, never built for both modes or for none. `set mode night` reads as dark only; `undo` compares colors as colors (`#F00` is the saved `#ff0000`); two headings words (`bold wide`, `bold and wide`) are one `new` line, and set's second line is the next step; a token in another style (`--color_accent`) or with a typo is offered as the token.
