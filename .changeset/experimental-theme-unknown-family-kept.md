[experimental] `astryx experimental theme editor set … font`: a family the editor does not know is kept as typed (Corben, Gabriela, Candal are real families, no typos of Corbel, Gabriola, Candara), with a note giving the line that sets the font a system ships spelled near it. A typo of a font preset is refused with the preset, a name listed both as a preset and a system font counted once (`Gerogia` reads as georgia), and the presets are read before the system fonts near it (`Corier` is courier, `Monlo` mono). Arial Narrow and Andale Mono are noted as fonts only macOS ships.
