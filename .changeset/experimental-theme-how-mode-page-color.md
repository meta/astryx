[experimental] `astryx experimental theme editor how`: a hue said for one mode's page, by itself ("dark mode should be a deep dark plum", "light mode is pale blush", "dark mode goes near-black with a purple tint") is now that mode's page in the color's hue, at the page's own lightness there, so the theme's surfaces follow it. Before, "dark mode should be … dark plum" made the whole theme dark-only, and other mode colors wrote nothing or only an accent. A mid tone named for a mode's background (chocolate brown) takes the page's lightness with its hue kept, and a hue said for everything ("blush pink everything") is the page. A color said with a part, a role or a token ("dark mode gets a red accent", "light mode gets blue links") reads as before, and the rest of the clause keeps the mode ("light mode should be cream with blue buttons").
