[experimental] `astryx experimental theme editor`: a whole border, border radius or shadow asked of a component whose controls sit side by side in a row that frames them (Pagination's pages in `pagination-list`) goes on that row, so the controls draw one strip. On a bar that shows a fill where the setting draws (a fill for every mode and variant, or for the setting's own; a see-through fill is no fill), they stay on the bar. `set` says where it wrote, and a fill set or undone later says which of them moves and how to put it back; a radius is refused while the row has no edge, naming the line that rounds each page. `how` routes a border or shadow the same way (an outline said in `how` reads as a border), and sends corners to the row only once the ask or the theme gives the row an edge, after that edge; otherwise they round each page. A side's border, a fill, an outline set with `set`, and the corners dial stay where they were.
