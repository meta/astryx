[experimental] `astryx experimental theme editor`: a border, border radius or shadow asked of a component whose controls sit side by side in a row that frames them (Pagination's pages in `pagination-list`) goes on that row, so the controls draw one strip; `set` says so with its undo, and refuses a radius while the row has no edge, naming the line that rounds each page. The corners dial still rounds each page. `how` puts an ask's corners on that row too once the row has an edge at rest, from the ask or the theme, and runs them after that edge, also in the corners' own answer. With no edge on the row, corners round each page as before.
