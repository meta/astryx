[experimental] `astryx experimental theme editor how`: a color bound ("darker but never darker than #1e40af") holds every color an answer writes, a color dial's seed included, and a see-through tint is held by its own color with its transparency kept, never turned into the opaque bound color. A part named on, inside or in a container ("links on cards") has its token set on that container, so it changes there only; one that cannot be kept there says so instead of changing it everywhere. "Outline buttons red" gives the outline look with the main button in red, never a border on every filled button. "All text 50% transparent" and "the text half transparent" set the theme's text colors at that opacity. A part's padding is read on its own pieces only (a table's cells, never a command palette inside a dialog), for value questions and comparisons alike.
