[experimental] `astryx experimental theme editor how` checks every command it suggests against the question: the command must make the kind of change the words ask for (a color for a color ask, a radius for a corner ask, padding or a size for a size ask, a border width, a weight, an opacity or a shadow), move the way they say from the value there now, and reach none or 0 for a removal. A command that does not is left out, and the answer says plainly what it could not work out; a value you typed is always taken as given.
