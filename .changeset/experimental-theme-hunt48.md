[experimental] `astryx experimental theme editor`: `--png` writes a picture only over one the editor took (unchanged since); a file of the user's by that name is named and left as it is, and no picture is taken. The record of the editor's pictures is a file of the theme (`<theme>.pictures.json`), so it moves and is copied with the theme. A `new` refused for its name never suggests a dial value the dial refuses: the value is left out and the refusal says so. A section sheet's out-of-date notice names `show <theme> --section <section>`, the command that makes it again. A theme folder renamed by hand is refused with every step it takes to edit it under the new name: the file renames and the names inside `<theme>.theme.ts`.
