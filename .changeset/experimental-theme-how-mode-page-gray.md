[experimental] `astryx experimental theme editor how`: a gray said for one mode's page ("dark mode is gray") gives that mode's page a neutral gray at the page's own lightness. Before, it wrote nothing. A gray already as readable as that page ("light mode should be light gray") is kept as said. On a theme that draws one mode, a gray said for that mode keeps the neutral reading.
