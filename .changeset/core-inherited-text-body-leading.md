[feat] Text inside a `Theme` that sets no line height of its own now uses the theme's body leading (`--text-body-leading`), as Core's own body text does, instead of the reset's 1.5. Plain text in a Card or Stack and a Blockquote's quote follow the theme's line height and move when a theme changes it. Core parts that set a text role's size now also set that role's leading, so none of them draws on an inherited line height (inline `Code` keeps the line of the text around it, and a few parts keep a fixed line height they are measured or aligned to: the Selector trigger, the Stepper step description and the chat composer): Table cells, header cells and row index numbers, Calendar month heading, day, weekday and week-number text, the touch date and time fields' titles, weekdays and wheels, Stepper step text, Pagination, Collapsible titles, Command Palette items, Dropdown and nav menu items, Selector and MultiSelector items and empty states, the Typeahead empty state, the chat trigger menu's empty and loading states, the chat system message and pasted-text details, Code Block sizes, Empty State compact text, Segmented Control and Token small sizes, the Switch description, the top nav menu's item descriptions, the chevron in a breadcrumb item's menu trigger, the Avatar Group overflow count, the skip link, Tokenizer and Slider labels. With the default theme, 14px text moves from 21px to 20px lines; 12px text in these parts moves to 20px lines (the supporting leading), from 18px or about 17px; 12px text that only inherits moves from 18px to about 17px; 17px text such as Collapsible titles moves from 25.5px to 24px; the Avatar Group overflow count's line grows inside its fixed circle. Text outside a Theme is unchanged.

To keep the old lines: for inherited text, set a line-height on your own container inside the Theme, or set `--text-body-leading` in your theme (which also sets Core's own body text). The listed parts follow their role's leading token instead (`--text-body-leading`, `--text-label-leading`, `--text-supporting-leading`, `--text-large-leading` or `--text-code-leading`): set that token in your theme, or style the part through its theming target.
