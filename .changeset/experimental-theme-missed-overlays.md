[experimental] `astryx experimental theme editor show`'s `missed` list names what keeps the base's look beside the theme's own, and each line changes the built theme:

- A tooltip or toast still on the base's dark inverted surface once the theme's own surfaces changed (a grey Win98-like theme) is listed, with a line that gives it the theme's surface in each mode the theme draws and readable text on it.
- A soft shadow beside square corners or a theme border (a popover's, a menu's, a dialog's) is listed, with a line that takes its blur away.
- A status fill (a banner's, a badge's status variants) is listed only where its dial builds a color of its own (the theme's vibrancy moved); at the base's vibrancy the dial gives the base's own color back.
- `how`'s answer for a part on that list (`how "make the tooltips match the theme"`) leads with the same line.
