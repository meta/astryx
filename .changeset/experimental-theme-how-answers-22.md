[experimental] `astryx experimental theme editor how`: a write for a clause that reads as an ask: an imperative, a thing with a value, a style word with a part, a wish about a named thing, or a description of the look wanted ("the page is white"). A tag question ("cards have a shadow, right?"), a hypothetical ("imagine …", "consider …"), a condition ("whenever …", "once …", "should the cards …"), sarcasm or a double negative gets the lookup instead. "nuke", "zero out", "sharpen", "flatten", `X++` / `X--` and `X: off` say which way to go; "dark.page=#…" and "dark mode only: accent #…" set dark mode.
