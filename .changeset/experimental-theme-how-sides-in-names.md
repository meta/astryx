[experimental] `astryx experimental theme editor how`: padding side words are read with the part's name taken out, so "code block padding" and "top nav padding" set every side of that part. "Card padding bigger (or smaller) than button padding" gives a step past (or under) the button's padding, never a copy of it. A dimension pair such as "16 x 16" is a size, never an amount.
