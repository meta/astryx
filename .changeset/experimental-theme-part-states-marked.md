[experimental] `astryx experimental theme editor`: the states Core marks on a part's own element are the part's to set. A list item (and so a checkbox list's row) takes `--state selected`, written as the attribute Core marks; a checkbox's or radio's box takes `--state hover` and the other moment states, shown from the part holding its invisible input instead of refused; a state asked of a container names the part inside it that has it, so `--on pagination --state current` points to the current page's button; and a part the drawing shows open in an overlay records its open state for `--state expanded`.
