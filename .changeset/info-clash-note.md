[experimental] `astryx experimental theme editor set <theme> accent <color>`: when the accent is a color far from the hue of the base theme's info, and the theme leaves info unset (a pink theme over a bright blue info), the result says info's banners and badges keep the base's color and offers an info between the two hues, so it sits with the palette and stays apart from the accent.
