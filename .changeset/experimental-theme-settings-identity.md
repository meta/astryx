[experimental] `astryx experimental theme`: the settings a theme's source extends are the settings module's own export, by identity anywhere up its `extends` chain, so a theme merely named like the settings is refused and one that reaches them through another theme is accepted. A source that stops loading is refused by `show` and never recorded as built. `compile` builds a family in a `font` shorthand like any font, leaves a family the app copy loads out of the full font help family by family, names a theme folder it cannot write with its fix, says in its JSON result the `--out` warnings text prints, and says that an editor theme's next set or show builds it without `--icons-specifier`. `set` and `show` give the install line for every built family nothing loads, a font token's included. A theme or an `extends` written as a helper's call or a conditional is named as what the build cannot follow, not as an inline icon registry.
