[experimental] `astryx experimental theme editor how` reads more asks the way they are meant:

- A top nav's links or items ("top nav links accent colored", "top nav items bigger", "navbar links bold") are its items. A longer part phrase now wins over a shorter one inside it, so the top nav and every link are no longer changed instead.
- A look named after a product ("make it Acme", "make it look like Acme") is never guessed. The answer says so and asks for its colors, font, corners and spacing, or a picture of it, whose colors `how` reads. "Look like before" is the earlier look, never a product: said of no part, the answer points to undo; "use the default theme" points to `astryx theme use` and the reset.
- One variant made to look like another ("ghost buttons look like the default button") takes that variant's look: what the theme sets on it, then the fill, text, border and shadow it draws, written for the asked variant only. It is no longer read as a reset. "The default" is the variant the part has when none is given. Said with "not" ("ghost buttons not look like primary buttons"), it writes nothing.
- A piece the ask says not to take away ("don't hide the copy button", "never hide the tab underline", "do not remove …") is kept: nothing is written, and the answer says so. A hide said negated ("un-hide the code block copy button", "stop hiding …") is a show: it takes back the theme's own hide, or says the piece is shown already; it is never `display none`; a hide or removal ruled out ("avoid hiding", "isn't hidden", "I don't want it removed") keeps the piece. A likeness said with a state or a mode writes nothing and says so; "not" or "never" before a look that is no likeness ("cards never get a shadow") is still read. A negation takes a piece away only when it names one ("no truncation", "top nav items without icons" hide nothing); an icon drawn inside a button is never hidden on its own (the button would stay, empty and focusable). Hiding a piece's background ("hide the code block header background") makes only its fill transparent. A piece that holds a control ("remove the dialog header", with its close button) is never hidden whole; the answer names the control. "Use the default theme" prints `astryx theme add <base>` before `astryx theme use <base>`, and a theme with no base says it has none to go back to. A top nav said beside a side nav ("the top nav links bold and the side nav items red") stays the top nav; only a bare "nav links" or "nav items" in a sidebar ask is the side nav's. Going back takes only words that ask for the earlier look ("darker than before" is a comparison). A look named after a product is a capitalized name ("make it pretty" describes).
