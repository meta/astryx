[experimental] `astryx experimental icon` answers a query of several words that no icon matches as a whole, such as a glyph named in a phrase with the control around it. Icons that carry some of its words come back as word matches (score 20), the icon carrying the rarest words first, and a word that names a definition the set maps an icon for counts twice for that icon; a word no icon carries counts for nothing. A word written as an export name (`SearchIcon`, `ChevronDownIcon`) now reads as its words. Word matches appear only where nothing answered before.
