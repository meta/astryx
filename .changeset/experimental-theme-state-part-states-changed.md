[experimental] `astryx experimental theme editor`:

- `how` keeps a state where another of the part's own states was changed only where both hold: a checked, disabled checkbox keeps Core's fill, and an unchecked one is left alone.
- A long answer is cut only between whole asks; the rest follows as the next runnable sequences.
- "remove the underline from tabs" makes the tab's indicator transparent where it paints.
- An input's focus ring is its box-shadow ring for a color, a width or a removal; in one mode only that mode changes, and status fields, which draw no ring while focused, keep none.
- A resting shadow on ringed parts keeps each render's own focus look, for every variant (selectors included) and for a write scoped to one status.
- A piece of a part Core has no part for ("the popover arrow", "the empty state icon", "sheet titles") is named and nothing is written for the whole part; a sheet is the bottom sheet, and an alert's title is the banner's own text.
- A toast's text color refused in one mode keeps that mode on the lines it offers.
- The corners help lists the step between round and pill among its rungs.
