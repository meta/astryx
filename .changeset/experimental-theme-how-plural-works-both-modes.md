[experimental] `astryx experimental theme editor how`: "headings that work in light and dark mode should be navy" colors the headings' text navy. A plural part said to work in both modes ("work", "look good", "hold up", "are usable") was cut at its "and", so the headings took a bold weight and the color went nowhere. It now reads as "headings in both modes should be navy". Because such an ask names usability, a text color that one mode's page makes hard to read ("links that are usable in light and dark mode should be navy") is still written for both modes, and the answer names that mode, the contrast ratio, and how to keep it readable there.
