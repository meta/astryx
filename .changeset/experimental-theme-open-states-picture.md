[experimental] `astryx experimental theme editor`: `--png` takes sheet-overlays.png beside preview.png, on `show` and on every change: every menu, tooltip, popover and list drawn open, in each mode the theme has. The sample page shows none open and the full sheet is too tall to read whole, so the result of `new` names it in its look-at-it line. A change without `--png` removes it with the other pictures, and names `show --png`, which takes it again. A typeahead, whose doc requires a search source, is rendered with a sample one in the catalog the part data is read from, so its list (`typeahead-dropdown`) is recorded and `how` reads it.
