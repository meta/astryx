[experimental] `astryx experimental theme editor how`:

- A value question is about the part the question names: "what color is the card title?" answers with the heading's color. "What color is the card's secondary text?" or "…the muted text?" answers with the secondary text color.
- A color named after a version of a part that has no fill of its own (the ghost button) no longer uses the main button's fill.
- "the buttons as tall as the small inputs" uses the small size, or says the small size has no height the editor can read. It no longer compares the default size.
- "2 times fainter" halves the text's strength.
- "everything rounder except the headings" works: headings have no corners, so they stay as they are.
