[experimental] `astryx experimental theme editor how`: "system sans 16px, 1.5 leading" sets the system font, the base text size and the body leading. "sans" after "system" or before a size is the typeface word, never "without", and a size said beside the theme's typeface ("serif 16px") is the base text size, as it already was beside a named family ("Georgia 16px").
