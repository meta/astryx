[experimental] `astryx experimental theme editor how`: "system sans 16px, 1.5 leading" sets the system font, the base text size and the body leading. "sans" before serif, a font word, the end of its clause, or a text size that ends the clause or comes before a text word is the typeface word; before any other word it is still "without" ("buttons sans 2px borders"), and a size said beside the theme's typeface ("serif 16px") is the base text size, as it already was beside a named family ("Georgia 16px").
