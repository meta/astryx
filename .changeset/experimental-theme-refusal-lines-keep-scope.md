[experimental] Every line a refusal of `astryx experimental theme editor set` offers keeps the scope typed: a `--state` or `--when` on the same part, and a `--mode`, go into the line whenever set takes it with them. A hovered link's color (`color '#00438a' --on link --state hover`) is now offered as `--color-text-accent '#00438a' --on link --state hover`, so following it changes the hovered link only, not every link at rest. A line set would refuse with a flag (a `--mode` on what is not a color) is still offered as the one that works.
