[experimental] `astryx experimental export`: a large exported page that repeats an element names each repeated list of the StyleX classes Astryx's packages write (the `x…` classes) by one short class in its first paint, when those repeated lists add up to at least 16 KB; the page's own StyleX classes keep their names, so a large table or list writes a much smaller file: a 10,000-row grid goes from 52 MB to 18 MB. The page looks the same, also where scripts are blocked; its script draws with StyleX's own classes, and `--reverse` gives the page back exactly. The experimental `render()` takes `keepClassNames: true` for a caller that styles the file's markup with its own copy of the StyleX styles.
