A value of another axis ("the high card shadow"), or a judging word that is also a value ("the divider border is too strong"), names no variant, and so does a value said before a part named in several words ("the muted clickable card") a variant word that is also a part's name ("the input selector", "the label citation"), or a going-back word ("the standard dialog"). This narrows the plain pronoun reading's "another variant keeps the earlier reading" to the variant forms named here.
