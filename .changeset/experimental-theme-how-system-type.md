[experimental] `astryx experimental theme editor how`: "bold system type" names no part. It makes the body text bold, as "bold system font" does; the font itself stays as it is. Looks said after it, "bold system type, blue accent" or "… and rounded corners", are written too. The system type said with another subject ("FABs 16px corners in the system type") leaves that subject unknown, as before.
