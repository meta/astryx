[docs] `Icon`'s documented `color` type now lists every value the component takes: the ten semantic colors and the ten palette colors (`blue`, `red`, `green`, `gray`, `cyan`, `teal`, `yellow`, `orange`, `pink`, `purple`). Before, the type listed only the semantic colors, though the description named the palette. Native platforms still draw only the semantic colors.
