[experimental] `astryx experimental theme editor how` reads three more kinds of words as what they say: a weight word before the text it describes, however many words about the text sit between ("thin elegant headings" is the weight, never a border around every heading); "reader" and "readers", which are no longer corrected to "header", so a book-reader ask changes the theme and not the app shell header; and a CSS custom property pasted from a stylesheet, whose last words name what it sets (`--brand-bg` is a background, `--brand-text` the text color), never the prefix a codebase repeats on every one of them.
