[experimental] `astryx experimental theme editor set <theme> focus ring|glow`: one setting for how keyboard focus looks on every focusable part. `glow` is a soft halo that hugs the part: the accent mixed with transparent, as soft as it can be while it reads at 3:1 on the page, a surface, a card and a menu in each mode. Where even the full accent does not read, the theme's own ring color stays, and a ring color the theme sets for one mode stays in that mode only. Fields, which ring themselves in their shadow, take the same halo on focus, in front of a resting shadow the theme gives them. `ring` is Core's own focus ring. The dial applies to the whole theme only.
