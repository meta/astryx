[experimental] `astryx experimental theme editor set <theme> focus ring|glow`: one setting for how keyboard focus looks on every focusable part. `glow` is a soft halo that hugs the part: the accent mixed with transparent, as soft as it can be while it reads at 3:1 on the page and a surface, and a readable color inside a part the theme fills; fields, which ring themselves in their shadow, take the same halo on focus, over a resting shadow the theme gives them. `ring` is Core's own focus ring. The dial applies to the whole theme only.
