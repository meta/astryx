- A starter's note for a font the CLI does not know names the stylesheet of each weight the theme uses, not the package's index sheet, which loads weight 400 alone.
- `show --png --section overlays` makes, photographs and lists the open states page once.

- A pipe or a folder at the pictures record is left as it is and named, and no picture is taken; the editor's writer never replaces a pipe, a device or a socket.
- A write of the same bytes a file already holds leaves the file as it is, so a refused command that puts back what it built changes nothing.
