[experimental] `astryx experimental theme editor set`: a step past a dial's last rung names an exact line only where one setting does it. On a part, spacing goes on in the control height the part reads ("bigger buttons" at the top rung offers `--size-element-md 46px --on button`); the text size offers a size it takes; the whole theme's spacing, which no one setting carries, claims no exact line. A one-mode theme reads its own mode named with `--mode` (`--mode dark` on a dark-only theme) as the same as no `--mode`, in `set` as in `undo`, and says so.
