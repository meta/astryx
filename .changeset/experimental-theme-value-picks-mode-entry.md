[experimental] `astryx experimental theme editor`: lines the editor offers run as offered. `undo` with a value one mode holds removes that mode's entry, and an undo of one of two settings says what each mode shows now; a theme typed second gets no line for a theme that does not exist; a dial or property name a letter off (`cornres`, `paddng`) gets its set line, with the value and scope kept; saved entries with their field names in other letters (`Thing`, `Value`) are read; a design token with a fallback (`var(--color-error, red)`) is offered as typed; and a setting typed where the theme goes (`undo accent`) gets that theme's undo, never a new theme of the setting's name.
