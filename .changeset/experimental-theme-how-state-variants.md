[experimental] `astryx experimental theme editor how` steps a part's text in a state, such as "make the disabled button text lighter", from each variant's own color. Each step is scoped to its variant and that state, so every variant moves the way asked. Before, one variant's color was written on all of them, and the secondary and ghost buttons moved the opposite way.
