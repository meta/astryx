[experimental] `astryx experimental theme editor show`'s `missed` and `unreached` lists name only what was missed, and each fix line works when followed:

- A state is named only when the part draws it as a look of its own (a selected nav item's fill); a readonly field on its surface and a checked switch's thumb are drawn so on purpose.
- A setting takes a part off a list only when it covers the aspect the list is about (the resting fill or text color, the fill in that state, the corners, the border); a hover fill or a corner radius leaves it listed.
- The disabled button's line covers only the variant drawn as the accent, and recolors its label with its fill.
- A status fill's line generates that status color (`set <theme> info …`), never the accent.
- An inverted surface (a toast) is named only when it no longer stands out from the page, with how's answer for it.
