[experimental] `astryx experimental theme editor set`: a look on a part names the parts drawn as it only where it reaches them: a ghost button's look names the parts drawn as ghost buttons (a calendar's arrows, a code block's copy button, an input's clear button, a toggle button), and a primary button's look names none of them. A padding a part draws through a variable of its own (a card's padding) reaches the parts drawn on its element that set none of their own (a clickable card, a selectable card), named with the line that keeps each at the padding Core gives it with no theme.
