[experimental] `astryx experimental theme editor`: lines offered work as the person will run them. A `new` refused for its name keeps each misspelled value as new repairs it for a free name. A word after `--like <base>` is read into the name, never glued onto the base. A damaged saved entry's set line is offered on its own only when it replaces that entry; otherwise it is labelled as the step after the undo. A typo of a built-in base reads as that base, installed or not, with its install first (set, `new --like` and a saved base alike), and an unknown base gets `how base`, never `base none` for a theme on a base. A thousands comma reads as such on a property that takes only whole numbers (`z-index '-1,000'`), and a comma in a ratio is a pair only between whole numbers of 1 or more (`0,75` is 0.75). An undo naming several settings offers one undo each; an undo with only a scope offers a step back only when there is one. A setting pasted in the saved form, or beside its scope keys, is one setting with its scope as flags. A word after a mistyped yes/no option is left out of the line and named. The settings reader reads a saved `only` of 1 or 0, refuses a vibrancy with no color as set does, and a saved step word steps from what applies without it.
