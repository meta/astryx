[experimental] `astryx experimental theme editor set … background <gradient> --on <part>`: a gradient or image set on a part (a button and its family) gives each part it reaches the theme's disabled treatment when disabled: the image comes off so the disabled fill shows, in every variant it reaches (the part's background rolls back to Core's disabled look). A disabled fill or image of the theme's own wins, whatever the order it was set in.
