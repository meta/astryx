[experimental] `astryx experimental theme editor set … --on <part>`: a color set on one part reaches only the family members that draw that same color (a toast's fill never becomes a banner's); a shape, an edge or a layered fill reaches every member drawn alike. A setting for a moment (hover, focus, pressed) reaches each member in the state where it draws that moment: a menu row's focus look lands on a list option's highlighted row.
