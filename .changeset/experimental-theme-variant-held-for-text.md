[experimental] `astryx experimental theme editor set … --on <part>`: a setting on one part that would make its text unreadable in one of its placements drawn on another ground, while it reads where the part is drawn at rest, keeps that placement at Core's look while the color fails there as the theme builds it: a top nav link colored for a dark top bar keeps Core's color in the phone menu (`mode:drawer`, on the menu's own surface), and a theme that darkens the phone menu too lets the light link color reach it. The result names it with the `--when` line that gives it there anyway, and one undo takes both back. The census records the placement each text was drawn in, the contrast checks measure a text in its placement, and a part's height at rest no longer counts a height Core gives it only in a placement. A state the theme paints a fill of its own for there (a selected link's block) keeps a readable color: the theme's own color for that state, else the setting's, in the fill's mode.
