[experimental] `astryx experimental theme editor set … --on <part>`: a setting on one part that would make its text unreadable in one of its placements drawn on another ground, while it reads where the part is drawn at rest, keeps that placement at Core's look: a top nav link colored for a dark top bar keeps Core's color in the phone menu (`mode:drawer`, on the menu's own surface). The result names it with the `--when` line that gives it there anyway, and one undo takes both back. The census records the placement each text was drawn in, the contrast checks measure a text in its placement, and a part's height at rest no longer counts a height Core gives it only in a placement.
