[experimental] `astryx experimental theme editor`: a hand-edited settings entry the editor refuses is offered only commands that unlock the theme. A `headings` value saved with no axis is its weight half, so `set <theme> headings <weight>` or `undo <theme> headings` replaces or removes it; a `mode` or `base` entry put in the settings list is removed by `undo <theme> mode` (or `base`), and no `set` line is offered for it (those set the theme's own mode and base).
