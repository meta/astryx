[experimental] The CLI ships the template icon table: for each icon meaning a bundled template draws, the Heroicon (or, for the lucide variant, the Lucide icon) that draws it. A private workspace package, `@astryxdesign/template-icons`, is generated from it, so template sources can import icons by meaning (`DeleteIcon`) and previews draw the same icons.
