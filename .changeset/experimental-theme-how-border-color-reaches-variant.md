[experimental] `astryx experimental theme editor how` now:

- moves only the control height of the size named when one is ("make the small buttons 4px taller"), on the part;
- reads a possessive owner's own element ("the dropdown menu's items") as that element, never the owner;
- treats a later "the shadows softer" or "the corners rounder" as a change to the theme's shadows or corners, never to the part named before.
