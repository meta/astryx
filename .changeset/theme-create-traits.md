[experimental] `astryx experimental theme create <name> --traits '<json>'` writes a new theme from a few typed traits (look, page, surface, text, accent, bar, font, corners, density, borders, shadows, surfaces, and exact tokens and components that win over the rest), builds it, adds it to the app, makes it the app's theme, and runs `astryx experimental theme check <name> --fix` on it, so every color ends with a light and a dark value. The file is yours to edit; run `astryx experimental theme check <name>` after each edit.
