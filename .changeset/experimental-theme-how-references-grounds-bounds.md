[experimental] `astryx experimental theme editor how`: after a contrast ratio, the part named after "on" is what it is measured against and is never changed ("the input border 3:1 contrast on the card"). A status banner's text steps its own status's text color, as its background does. A part that reads a value from several tokens (a heading's weight, one per level) answers each value. The page is the whole theme for a dial ("the page density compact"), and its colors are its body colors, so "equal to the page background" and "as light as the page" read them. "As dark as dialogs" takes the dialog's fill. Striped table rows step the color Core paints the stripes with. "Outline buttons thicker" keeps the width change beside the outline look. A length bound on the corners dial ("never more than 8px") holds every radius the dial writes.
