[experimental] `astryx experimental theme editor how` sets a file named in `url()` aside before the question reader's readers of the whole ask take their copy, so inside the question reader a word of its path changes no other ask: in "menus opacity 0.9, cards background-image: url(/img/frosted.png)", "frosted" no longer turns the menus' opacity into a fill alpha. (The checks that run before the question reader, such as the color-blind one, still read the raw ask.)
