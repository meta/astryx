[experimental] `astryx experimental theme` and `astryx experimental render`: a stop (Ctrl-C, SIGTERM, or the terminal closing) while pages render removes the render's temp folders. A page with a root Theme is written with that Theme's attributes on `<html>`, as Core's root Theme sets them in a browser, so root-scoped tokens such as the focus ring's color follow the theme in the preview and the sheet. Every `preview app` command a result names works where it is printed: a folder starting with `-` goes after `--`, a folder is given from the folder the command ran in, a theme a workspace app holds is reached from that app, and a repaired folder name is a free one. A starter app gets every open font the theme builds, installed in this project or not. A change names the pictures it removed (the preview's and the sheet's) and keeps a section sheet's. `preview app --theme` refuses a theme whose own files import a file outside its folder, which the new app would not have. A stop during `preview app` says whether the app was written whole or nothing was written.
