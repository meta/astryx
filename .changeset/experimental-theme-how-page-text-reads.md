[experimental] In `astryx experimental theme editor how`, a page color said for a mode is now checked against the theme's text in that mode. When the primary or secondary text would not read on it, a second line sets a readable text color. "Light mode only: … pure white instead of its current color" now writes the light page; before, it wrote the dark one.
