[experimental] `astryx experimental theme editor`: a setting listed twice by hand now changes the last entry, the one the build reads, so "keep pill" saves and builds pill. A damaged mode or base written in other letters or as a package name (`Dark-Only`, `Neutral`, `@astryxdesign/theme-neutral`) is fixed first by the suggestions, and a change to another setting cleans it to the value meant instead of resetting it. A stored vibrancy of `0.5` is offered as 50. `new` cleans each flag value the way `set` does, so `--font '«Georgia»'` saves `"Georgia"`. `--on "text inputs"` and `--on "dialog header"` name text-input and dialog-header, and `--when Variant:Primary` or `variant=primary` gets the corrected command. An app copy the editor wrote, left without its `themes/<name>/` folder, is named as the editor's with `new <name>` to make it again. Names copied from the app (`tTheme`, `tTheme.ts`, `brand.theme.ts`, `themes//t`, `BrandDark`, `Brand Dark`) reach the theme they name, and `new` says when it is here already. The note after Ctrl-C says what `undo` or `new` saved, with the project's own CLI command. An undo of padding in the other form (a side or the shorthand) suggests the undo that matches what is saved.
