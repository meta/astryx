[experimental] `astryx experimental theme editor …`: a set of a property typed in other letters (`set t Background-Color green --on card`) is that property, so it fixes that property listed twice in the settings file, instead of a refusal that offers a swapped line back and forth. A top-level `base` in the settings file (the editor's word for it) is read as the base, with a note, instead of the theme building on no base.
