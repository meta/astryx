[experimental] `astryx experimental theme preview add`: a folder name that Next serves at a plain URL (letters, digits and `. _ ~ ! $ & ' ( ) + , ; = @ -`) is accepted. For any other name, every odd segment is slugged and the suggested folder is a free one. A folder that differs from another only in case is refused, since macOS and Windows treat them as one. In an app with no TypeScript, the result names the install line. When the app's tsconfig turns on `noUncheckedIndexedAccess`, the result names the template pages written as their template ships. The Colors page shows a seed color as it is stored.
