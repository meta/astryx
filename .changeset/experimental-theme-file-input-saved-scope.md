[experimental] `astryx experimental theme …`: the settings file and pasted forms are read as typed input. A saved setting whose `on`, `when` or `state` is not text (`"when": 5`, `"on": {}`), or whose part is empty, no longer makes every command fail: it is refused as a damaged setting with an undo line that removes it. A set of headings replaces a saved headings entry whose axis names no half, so later commands work. A saved base written `None` (in any letters) is no base, and the file's own field names in other letters (`Like`, `Settings`, `Mode`) are those fields. A pasted entry's field spelled as its flag (`"--on": "card"`) is that field, and a pasted change line with the `→` arrow, a label before its colon, or a label and colon with no old value keeps the label as the mode. An empty pasted object points to the dials and the help. `undo t 'accent red'` reads the setting and its value as set does. A swapped setting and value whose setting is misspelled (`set t pill cornres`) gets the swap line.
