[experimental] With an icon set installed, `astryx search` answers a query that asks for an icon (`trash icon`, `SearchIcon`, or a set's name) with up to three of the installed icons that answer it, after the results: `icons` in the JSON, one line each in the text. The results and their count do not change, a search with `--type` lists no icons, and with no icon set installed every search answers as before.
