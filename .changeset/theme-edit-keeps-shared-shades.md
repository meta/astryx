[experimental] `astryx experimental theme editor`: a theme added from a shared theme with a palette a newer CLI made keeps the palette shades its app copy shows through the editor's first build there (opening it, showing it, or a change that leaves the colors alone), instead of picking some again. That build reads those shades from the app copy's stylesheet, each as the saved palette's stop that holds its color in that mode; a half no stop holds follows the base theme where the copy shows the base's value, else keeps the color the copy shows. A base change, or a working file changed by hand since the add, moves them, as before.
