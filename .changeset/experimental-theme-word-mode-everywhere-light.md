[experimental] `astryx experimental theme editor`: one reading for each kind of word. A mode is read one way everywhere (the `--mode` flag, a mode label in a value, a saved entry's mode and the settings file's mode): light or dark in its written forms, or day, daytime, night or nighttime; black, white, dim and bright are no longer read as modes. A base is read one way by `new`, set and the settings file. A `new` on a base that is not installed leads with the install, then the same `new` on that base, as set does. `how` reads state words from one table. A font file in a family list is found with the one family-list reader.
